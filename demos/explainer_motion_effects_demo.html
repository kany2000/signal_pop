科技解说视频动效拆解 Demo

对应《Openclaw 2.0 震撼發佈》（商業本質）同类型口播解说视频的 5 种核心动效，用 CSS 关键帧 + 缓动曲线实现。 每个舞台可点 ▶ 重播，说明区标注了实现要点与 Remotion 对应写法。

① 逐字浮现 · 关键词强调

Kinetic Typography
实现要点：每个字是独立的 inline-block，初始 opacity:0 + translateY(24px) + blur(4px)，用 animation-delay: calc(var(--i) * 0.08s) 逐字错峰（stagger）。缓动用 cubic-bezier(0.22, 1, 0.36, 1)（easeOutQuint 类），快出缓停，比 linear 高级。
Remotion 对应：interpolate(frame - i*2, [0,15], [24,0]) 逐字偏移 + spring() 弹性；关键词换色直接改 style。

② 数字滚动 · 数据可视化

Count-up
0
贡献者
0
首次贡献
0
合并请求
实现要点：requestAnimationFrame 按 easeOutCubic 从 0 滚到目标值（1.4s），font-variant-numeric: tabular-nums 防数字抖动；三组数字再整体错峰入场（0/0.25/0.5s）。旁白念到哪组，哪组才入场——这是此类视频"数据感"的核心。
Remotion 对应：interpolate(frame, [0, 84], [0, 933], {easing: Easing.out(Easing.cubic)}) 取整渲染。

③ 任务进度卡 · 状态可视化

Progress Card
自动处理学校邮件提醒
读取指定邮箱
提取活动日期
区分新旧事件
发送 Telegram 提醒
实现要点：卡片整体 scale 0.92→1 + 上移 弹入（带轻微超调的 back-out 缓动）；内部步骤按 --i * 0.45s 逐条滑入，完成项的进度条 width 0→100% 同步生长，"进行中"项用 ◐ 无限旋转。进度卡呼应旁白里的"持久化进度卡"卖点。
Remotion 对应：Sequence 嵌套 + 每步一个 spring({fps, frame: frame-offset})；进度条宽度用 interpolate。

④ Ken-Burns 缓推 · 底图防静止

B-roll Motion
系统需要知道此前处理了什么，哪些变化值得再打扰一次
实现要点：背景层 6 秒 scale 1→1.12 同时轻微位移（translate(-1.5%, 1%)），让静态截图/图片"活"起来——口播视频画面不闷的关键；字幕条延迟 0.6s translateY(16px)→0 上浮，关键词变色。真实项目里把 kb-img 换成 background-image 即可。
Remotion 对应：信号弹管线已在用的 ken-burns 就是这个原理（transform: scale(interpolate(frame,[0,180],[1,1.12]))）。

⑤ 双滑对撞转场 · 章节切换

Transition
模型负责"想"
Openclaw 负责"做"
职责分离
实现要点：左右两块从两侧滑入对撞（右块延迟 0.08s 制造层次），中心徽章用带超调的 cubic-bezier(0.34, 1.56, 0.64, 1)（back-out）弹出——"对撞 + 弹徽章"是章节标题的经典组合，用来把旁白里的对比概念（模型 vs 执行层）可视化。
Remotion 对应：两个 Sequence 各自 translateX(interpolate(...))；徽章用 spring({damping: 12})。

工具链对照（这类视频通常怎么生产）

环节剪映/CapCut 流（最快）AE 模板流（最精致）Remotion 流（信号弹管线，可全自动）
逐字字幕/关键词强调"文字pro"自带逐字动画，跟音频自动打轴TypeMonkey / Kinetic Typer 脚本逐字 Sequence + spring（同效果①）
数字滚动贴纸/文字模板表达式 ease(time)interpolate + easing（同效果②）
进度卡/图表素材库模板套用形状图层修剪路径React 组件直接画（同效果③，逻辑可写活）
b-roll 缓推关键帧缩放父子级+摆动ken-burns（已在管线中，同效果④）
章节转场转场库一键预合成+蒙版对撞 Sequence（同效果⑤）

注：以上为基于旁白文本与同类频道风格的通用还原（原视频画面在本环境无法逐帧核实）；但 5 种效果覆盖了此类"科技产品深度解说"视频 90% 以上的动效语言。要看真实逐帧拆解，把视频文件放到项目目录即可。
